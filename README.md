# castor_genome
This repository contains scripts and resources for Chromosome-level genome assembly of two parents of Gujarat Castor Hybrid GCH-7 (SKI-215 &amp; SKP-84).

### Assembly accessions
`
The primary genomes are available at NCBI under the accession [JCAWEN000000000](https://www.ncbi.nlm.nih.gov/nuccore/JCAWEN000000000.1) and [JCAWEO000000000](https://www.ncbi.nlm.nih.gov/nuccore/JCAWEO000000000.1).
`
### Genome and Annotations related files available on FigShare
The annotations are available at https://doi.org/10.6084/m9.figshare.31911283
